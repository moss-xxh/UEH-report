# 📊 企业微信用户数据统计机器人

## 功能说明

机器人每天定时向企业微信群推送用户数据报告，包含：
- **今日新增用户** - 对比昨日涨跌
- **今日退出用户** - 对比昨日涨跌
- **目前总用户数** - 对比昨日涨跌
- **数据对比表格**

## 🚀 快速开始

### 1. 获取企业微信Webhook

1. 在企业微信群中，点击右上角 `···`
2. 选择 `群机器人` -> `添加机器人`
3. 复制生成的 Webhook 地址

### 2. 配置机器人

编辑 `config.py` 文件：

```python
# 替换为你的Webhook地址
WECOM_WEBHOOK = "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=你的key"

# 设置推送时间
STATS_CONFIG = {
    "schedule": {
        "daily_report_time": "09:00",  # 每天早上9点推送
        "timezone": "Asia/Shanghai"
    }
}
```

### 3. 配置数据源

编辑 `user_stats.py` 文件，修改数据获取逻辑。

#### 方式1：从MySQL数据库获取

```python
def get_today_stats(self) -> Dict:
    import pymysql

    conn = pymysql.connect(**self.db_config)
    cursor = conn.cursor()

    # 今日新增用户
    cursor.execute("""
        SELECT COUNT(*) FROM users
        WHERE DATE(created_at) = CURDATE()
    """)
    new_users = cursor.fetchone()[0]

    # 今日退出用户
    cursor.execute("""
        SELECT COUNT(*) FROM users
        WHERE DATE(deleted_at) = CURDATE()
    """)
    exit_users = cursor.fetchone()[0]

    # 目前总用户数
    cursor.execute("""
        SELECT COUNT(*) FROM users
        WHERE deleted_at IS NULL
    """)
    total_users = cursor.fetchone()[0]

    conn.close()

    return {
        'new_users': new_users,
        'exit_users': exit_users,
        'total_users': total_users
    }
```

#### 方式2：从API接口获取

```python
def get_today_stats(self) -> Dict:
    import requests

    response = requests.get('http://your-api.com/user-stats')
    data = response.json()

    return {
        'new_users': data['new_users'],
        'exit_users': data['exit_users'],
        'total_users': data['total_users']
    }
```

## ⚙️ 高级配置

### 选择报告类型

编辑 `send_user_stats.py`，修改第43行：

```python
bot = UserStatsBot(
    webhook_url=WECOM_WEBHOOK,
    report_type='detailed'  # 'detailed'=详细版  'simple'=简洁版
)
```

**详细版**：包含完整表格和对比数据（推荐）
**简洁版**：只显示关键数字，更简洁

### 多次推送

如果想一天推送多次，编辑 `send_user_stats.py` 的 `main()` 函数：

```python
# 早上9点推送
bot.setup_schedule("09:00")

# 下午6点也推送
bot.setup_schedule("18:00")

bot.start(blocking=True)
```

### 自定义报告内容

编辑 `user_stats.py` 中的 `format_user_report()` 函数，可以：
- 修改颜色标记
- 添加新的数据项
- 调整表格格式
- 添加图表emoji

## 📊 数据库表结构参考

假设你的用户表结构：

```sql
CREATE TABLE users (
    id INT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50),
    created_at DATETIME,        -- 注册时间
    deleted_at DATETIME DEFAULT NULL,  -- 注销时间（NULL表示未注销）
    -- 其他字段...
);
```

对应的SQL查询：

```sql
-- 今日新增用户
SELECT COUNT(*) FROM users WHERE DATE(created_at) = CURDATE();

-- 今日退出用户
SELECT COUNT(*) FROM users WHERE DATE(deleted_at) = CURDATE();

-- 目前总用户（排除已注销）
SELECT COUNT(*) FROM users WHERE deleted_at IS NULL;

-- 昨日数据（把CURDATE()改成CURDATE() - INTERVAL 1 DAY）
```

## 🔧 故障排除

### 1. 消息发送失败

**检查项：**
- Webhook地址是否正确
- 网络是否正常
- 查看日志：`cat user_stats_bot.log`

### 2. 数据不准确

**检查项：**
- 数据库连接是否正常
- SQL查询逻辑是否正确
- 时区设置是否正确

### 3. 定时任务不执行

**检查项：**
- 进程是否在运行：`ps aux | grep send_user_stats`
- 系统时间是否正确：`date`
- 查看日志文件

## 📞 常见问题

A: 可以！创建多个机器人，使用不同的Webhook即可

**Q: 能否按需推送而不是定时？**
A: 可以！直接运行 `python3 send_user_stats.py --test`

A: 可以！修改 `user_stats.py` 的 `format_user_report()` 函数添加更多指标

**Q: 支持图表吗？**
A: 企业微信机器人只支持文本和Markdown，不支持图表图片推送
