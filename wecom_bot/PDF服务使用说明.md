# 📄 VPP PDF报告服务使用说明

## 功能说明

现在企业微信机器人的"查看详细数据"按钮可以直接预览详细的PDF报告了！

**流程：**
1. 企业微信群收到VPP运行报告卡片
2. 点击"查看详细数据"按钮
3. 自动打开浏览器，显示详细的PDF报告

---

## 🚀 快速启动

### 1. 启动PDF服务

```bash
cd /Users/xuexinhai/Desktop/1/wecom_bot
python3 pdf_server.py
```

看到以下输出表示服务启动成功：

```
============================================================
🚀 VPP PDF报告服务启动
============================================================
访问地址: http://localhost:5000
PDF报告: http://localhost:5000/report/pdf
============================================================
```

### 2. 保持服务运行

PDF服务需要一直运行才能响应点击请求。

**方式1：前台运行（推荐测试时使用）**
```bash
python3 pdf_server.py
```

**方式2：后台运行（推荐正式使用）**
```bash
nohup python3 pdf_server.py > pdf_server.log 2>&1 &

# 查看日志
tail -f pdf_server.log

# 停止服务
ps aux | grep pdf_server.py
kill -9 [进程ID]
```

### 3. 测试PDF生成

发送测试消息到企业微信：

```bash
python3 send_user_stats.py --test
```

### 4. 点击查看详细数据

在企业微信群中，点击卡片上的"查看详细数据"按钮，会自动打开浏览器预览PDF报告。

## 📊 PDF报告内容

PDF报告包含以下详细数据：

1. **核心指标对比表**
   - 调度次数（今日 vs 昨日）
   - 充电次数（今日 vs 昨日）
   - 放电次数（今日 vs 昨日）
   - 累计馈网量（今日 vs 昨日）
   - 今日获利（今日 vs 昨日）

2. **用户数据表**
   - 今日新增用户
   - 今日退出用户
   - 目前总用户
   - 净增长

3. **地区调度详情表**
   - 时间、地区、充电/放电类型、设备数量

## 🔧 进阶配置

### 修改PDF样式

编辑 `pdf_generator.py` 文件中的：
- `title_style`：标题样式
- `TableStyle`：表格样式
- 颜色、字体、间距等

### 修改服务端口

如果5000端口被占用，可以修改 `pdf_server.py` 最后几行：

```python
app.run(
    host='0.0.0.0',
    port=8080,  # 改成其他端口
    debug=True
)
```

**同时记得修改** `wecom_client.py` 中的URL：

```python
"url": "http://localhost:8080/report/pdf"  # 端口要一致
```

### 外网访问（可选）

如果需要从外网访问（比如在手机微信上点击），需要：

1. **方案1：使用内网穿透工具**
   - 使用 `ngrok`、`frp` 等工具
   - 获得公网域名
   - 修改 `wecom_client.py` 中的URL为公网地址

2. **方案2：部署到云服务器**
   - 将整个项目部署到云服务器
   - 配置域名和SSL证书
   - 修改URL为服务器地址

## 🔍 测试接口

PDF服务提供了几个测试接口：

1. **首页** - `http://localhost:5000/`
   - 查看服务状态和测试链接

2. **PDF报告** - `http://localhost:5000/report/pdf`
   - 直接在浏览器中预览PDF

3. **统计数据** - `http://localhost:5000/api/stats`
   - 查看原始JSON数据

4. **健康检查** - `http://localhost:5000/health`
   - 检查服务是否正常运行

可以在浏览器中直接访问这些地址进行测试。

## ⚠️ 注意事项

1. **PDF服务必须保持运行**
   - 如果服务停止，点击"查看详细数据"会报错
   - 建议使用 `nohup` 后台运行

2. **内网访问限制**
   - 默认配置只支持本地或局域网访问
   - 如果在手机微信上点击可能无法打开
   - 需要配置外网访问（见上方"外网访问"部分）

3. **数据实时性**
   - PDF报告是点击时实时生成的
   - 会自动获取最新的统计数据

4. **中文字体问题**
   - 如果PDF中文显示有问题，需要安装中文字体
   - 可能需要修改 `pdf_generator.py` 中的字体路径

## 🛠️ 故障排除

### PDF服务无法启动

**检查端口占用：**
```bash
lsof -i:5000
```

**解决方法：**
- 杀掉占用端口的进程
- 或修改服务端口（见上方"修改服务端口"）

### 点击按钮无法打开

**检查服务是否运行：**
```bash
curl http://localhost:5000/health
```

**如果返回错误：**
- 确认PDF服务是否启动
- 查看服务日志：`tail -f pdf_server.log`

### PDF中文乱码

修改 `pdf_generator.py` 中的字体设置：

```python
# 使用系统中文字体
pdfmetrics.registerFont(TTFont('SimSun', '/path/to/chinese/font.ttf'))
```
