1. 打开 report_template_modern.html
2. 按 Cmd + P (Mac) 或 Ctrl + P (Windows)
3. 打印设置：

   ┌─────────────────────────────────────┐
   │ 目标：另存为 PDF                     │
   │ 页面：全部                           │
   │                                     │
   │ ▼ 更多设置                          │
   │   ✅ 背景图形 ← 必须勾选！          │
   │   边距：无    ← 封面铺满全页！      │
   │   纸张：A4                          │
   │   缩放：100%                        │
   └─────────────────────────────────────┘

4. 点击"保存"
