# VPP运维报告 - PDF导出说明

## 问题原因

浏览器默认在打印时会移除背景图片和背景色(为了节省墨水),导致封面显示为白色。

## 解决方案

已经在代码中添加了 `print-color-adjust: exact` 强制打印背景,但您仍需要在浏览器打印设置中启用背景图形选项。

---

## 导出步骤

### Chrome / Edge 浏览器

1. **打开报告文件**
   - 双击 `report_template_modern.html` 在浏览器中打开

2. **打开打印对话框**
   - 点击页面上的"导出 PDF"按钮
   - 或按快捷键: `Cmd + P` (Mac) / `Ctrl + P` (Windows)

3. **配置打印设置** ⚠️ 重要步骤
   - **目标**: 选择"另存为 PDF"
   - **页面**: 全部
   - **更多设置** 展开后:
     - ✅ **勾选"背景图形"** (Background graphics) - 必须勾选!
     - 纸张大小: A4
     - **边距: 无** ⚠️ 重要! 选择"无"才能封面铺满全页
     - 缩放: 默认 (100%)

4. **保存PDF**
   - 点击"保存"按钮
   - 选择保存位置
   - 输入文件名,点击保存

### Safari 浏览器 (Mac)

1. **打开打印对话框**
   - 点击"导出 PDF"按钮或 `Cmd + P`

2. **展开打印选项**
   - 点击左下角"显示详细信息"

3. **启用背景打印**
   - ✅ 勾选"打印背景" (Print backgrounds)

4. **保存PDF**
   - 点击左下角"PDF" → 选择"存储为PDF"

### Firefox 浏览器

1. **打开打印对话框**
   - 按 `Cmd + P` (Mac) / `Ctrl + P` (Windows)

2. **配置设置**
   - 目标: 选择"保存为 PDF"
   - ✅ 勾选"打印背景" (Print backgrounds)

3. **保存文件**
   - 点击"保存"

## 常见问题

### Q1: 为什么我勾选了"背景图形",封面还是白色?

**A:** 请尝试:
1. 刷新页面后重新打印: `Cmd + Shift + R` (Mac) / `Ctrl + Shift + F5` (Windows)
2. 清除浏览器缓存后重试
3. 使用 Chrome 或 Edge 浏览器(推荐)

### Q2: 封面有蓝色渐变,但没有背景图片?

**A:** 背景图片可能未加载成功:
1. 检查 `cover.jpg` 和 `report_template_modern.html` 是否在同一文件夹
2. 刷新页面,等待图片加载完成后再打印
3. 右键点击封面区域 → "检查",查看控制台是否有图片加载错误

### Q3: 可以直接右键"打印"吗?

**A:** 可以,但务必记得在打印设置中勾选"背景图形"选项!

### Q4: PDF文件太大怎么办?

**A:** 封面包含高分辨率图片,文件会较大(约1-2MB)。如果需要压缩:
- 使用在线工具: smallpdf.com 或 ilovepdf.com
- 或在打印设置中降低图片质量

## 技术说明

代码中已添加以下CSS确保打印时保留背景:

```css
@media print {
    * {
        -webkit-print-color-adjust: exact !important;
        print-color-adjust: exact !important;
        color-adjust: exact !important;
    }

    .cover-page {
        background-image: url('cover.jpg') !important;
        background-size: cover !important;
    }
}
```

但浏览器的"背景图形"选项优先级更高,所以必须在打印设置中手动启用。
