## 📋 日常使用

### 方式1：定时自动推送（推荐）

编辑 `config.py` 设置推送时间：

```python
STATS_CONFIG = {
    'schedule': {
        'daily_report_time': '09:00'  # 每天早上9点推送
    }
}
```

启动定时任务：

```bash
python3 send_user_stats.py
```

程序会一直运行，每天定时发送消息。

### 方式2：手动测试发送

随时发送测试消息：

```bash
python3 send_user_stats.py --test
```

## 🖥️ 进阶使用

### 后台运行Flask服务器

**macOS/Linux:**

```bash
# 方法1：使用 nohup
nohup python3 pdf_server.py > pdf_server.log 2>&1 &

# 方法2：使用 screen
screen -S vpp_server
python3 pdf_server.py
# 按 Ctrl+A 然后按 D 退出screen

# 方法3：使用 tmux

python3 pdf_server.py
# 按 Ctrl+B 然后按 D 退出tmux
# 恢复: tmux attach -t vpp_server
```

**停止后台服务：**

```bash
# 查找进程
ps aux | grep pdf_server

# 停止进程（替换PID为实际进程号）
kill <PID>
```

## 🔧 配置说明

### 修改推送时间

编辑 `config.py`:

```python
STATS_CONFIG = {
    'schedule': {
        'daily_report_time': '09:00'  # HH:MM 格式
    }
}
```

### 修改服务器端口

编辑 `pdf_server.py` 最后几行：

```python
app.run(
    host='0.0.0.0',
    port=8080,  # 改为其他端口，如 8081
    debug=True
)
```

**重要**：修改端口后，需要同步更新 `wecom_client.py` 中的URL：

```python
"url": "http://127.0.0.1:8081/report/html"  # 端口改为8081
```

### 修改数据源

编辑 `user_stats.py` 中的数据采集逻辑，连接真实数据库。

## 🐛 常见问题

### Q1: 启动时提示"Address already in use"

**原因**：端口8080已被占用（可能是之前的进程未关闭）

**解决方法：**
```bash
# 查找占用端口的进程
lsof -i :8080

# 杀死进程（替换PID）
kill <PID>

# 或者改用其他端口（见"配置说明"）
```

### Q2: 企业微信消息发送失败

**检查清单：**
- ✅ Webhook URL是否正确（在 `config.py` 中）
- ✅ 网络连接是否正常
- ✅ 企业微信机器人是否被禁用

**测试Webhook：**
```bash
# 发送简单测试消息
python3 -c "from wecom_client import WeComBot; from config import WECOM_WEBHOOK; WeComBot(WECOM_WEBHOOK).send_text('测试消息')"
```

### Q3: 点击"查看详细数据"无法打开页面

**检查清单：**
- ✅ Flask服务器是否在运行
- ✅ 访问 http://127.0.0.1:8080/health 是否返回正常
- ✅ 防火墙是否阻止了8080端口

**解决方法：**
```bash
# 重启服务器
kill $(lsof -t -i:8080)
python3 pdf_server.py
```

### Q4: HTML报告数据不更新

**原因**：数据是每次请求时动态生成的，应该会自动更新。

**解决方法：**
- 刷新浏览器页面（Cmd+R）
- 检查 `user_stats.py` 的数据采集逻辑

### Q5: 如何在其他设备上访问报告？

**方法：** 使用局域网IP地址

1. 查看本机IP：
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

2. 在其他设备浏览器中访问：
```
http://<本机IP>:8080/report/html
例如：http://192.168.100.106:8080/report/html
```

**注意**：需要在同一局域网内。
